# 麦麦 Corgi IME

一只不催绩效的柯基，陪你用中文输入法工作。

这是 **Rime 原生输入法扩展 + Electron 桌面伴侣**，不是浏览器里的模拟输入框，也不把英文键盘敲击冒充中文字符。底座为 macOS 的 [鼠须管 Squirrel](https://github.com/rime/squirrel) / Windows 的 [小狼毫 Weasel](https://github.com/rime/weasel)，独立“柯基拼音”方案复用 [朙月拼音](https://github.com/rime/rime-luna-pinyin) 词典。原生输入法和词典不随本包重分发，请从官方安装。

## 0.5 环状快捷互动

只有鼠标触到柯基身体才展开六方向的环状按钮，外围空白不会触发。按钮固定在上、右上、右下、下、左下、左上，44 像素命中范围；淡入不移动或缩放，方便快速点按。展开后从柯基移到按钮或间隙会保持，离开整个互动区域才收起。

## 0.4 悬停互动（保留功能）

鼠标移到柯基附近，周围浮现六枚独立按钮：摸摸、饼干、喝水、休息、专注、设置。每枚可直接点击，不会触发拖动或误摸柯基。按钮与柯基共享悬停范围，移动到按钮不会提前收起；离开约 180 毫秒后收起，移出应用窗口立即收起。拖动、设置及待处理提醒期间隐藏，底部仍无常驻工具条。原有右键菜单和手势保留。

## 能做什么
- 原生 Rime 普通中文上屏后，仅累加 Unicode 码点数量，不传递或保存正文。
- 默认每 120 字摇尾巴鼓励，30 秒冷却防刷屏；可改 20–10000 字。
- 无常驻下方图标：单击摸摸、双击喂饼干、拖动换位置，右键菜单访问所有功能；喝水水碗动画；每次互动有动画、文案或计数反馈。
- 柯基大小可在设置中调整（50%–150%，默认 50%）；打开设置时自动恢复可读尺寸。
- 25 分钟专注钟；喝水（默认 30 分钟）和休息（默认 45 分钟）可分别启停并设置 1–240 分钟间隔。
- 到时卡片支持「已完成」「10 分钟后」「关闭该类提醒」，并显示本次陪伴的摸摸、饼干、喝水、休息次数。
- 提醒设置持久保存；关闭应用时不提醒，重启从新间隔开始。本次互动次数在重启后重置。
- 默认不抢焦点；右键设置；macOS/Windows 使用透明空白区域穿透（待对应实机确认），Linux 录制环境使用接收鼠标的兼容模式，不承诺透明区域穿透。窗口在屏幕边缘夹紧。
- 没有账号、云端、LLM 调用、遥测、HTTP 服务或全局键盘钩子。

## 0.3 轻轻散步

最近 2 分钟有 Rime 新上屏，或专注计时中，麦麦每隔约 30–50 秒走 90–150 像素，速度约 18 像素/秒。鼠标靠近、拖动、提醒卡片、打开设置或暂停陪伴时停下；拖动后至少安静 30 秒。菜单和设置可关闭散步，开关会保存。右键「散步一小圈」可随时演示，移开鼠标后开始。

只在当前显示器的工作区走动，不跨屏追踪鼠标，不读取正在使用的应用。拔屏/分辨率变化会重新夹紧。屏幕若比窗口小，只能将窗口左上角保留在屏内，无法保证全部内容可见。走动不调用 focus；只有主动打开设置才获得焦点。首次提示 7 秒后淡出，字数在鼠标靠近柯基时显示。

## 安装与首次验收

1. 安装官方 Squirrel / Weasel。需包含 `librime-lua`，并已安装、部署 `luna_pinyin`（朙月拼音）方案。通过系统输入法先确认它能在 TextEdit / 记事本输入中文。
2. 解压对应桌面包运行 `Corgi IME`。预览版未签名/公证；若系统拦截，不要全局关闭安全防护，按官方本机允许单个应用的流程处理，或在本机从源码构建。
3. 右键柯基 → 设置与输入法安装。默认目录 macOS `~/Library/Rime`，Windows `%APPDATA%\Rime`；自定义安装路径需用“选择目录”。
4. 点击“安装扩展”，确认修改范围。安装器先检查词典、拒绝覆盖同名扩展、备份原配置，然后加入独立方案。已有配置特殊格式或存在修改时会安全拒绝。
5. 在 Rime 菜单执行“重新部署”，切换“柯基拼音”。安装器不调用管理员权限、不修改系统输入源、不自动切换输入法。
6. 在 TextEdit / 记事本输入并**上屏**“你好世界”。桌宠下一次轮询（约 1.5 秒）显示今日字数。设阈值 20，再上屏 20 字验收鼓励。

若没有绿色连接点，检查是否选中柯基拼音、重新部署是否成功、词典和 Lua 模块是否可用。安装器只能检查用户目录中的 `luna_pinyin.dict.yaml` 或已编译 `build/luna_pinyin.table.bin`，不能保证 Rime 服务已加载 Lua。

## 隐私与统计口径

- **暂停鼓励与提醒**：柯基休息，不累计暂停期间的奖励进度，提醒暂停，专注倒计时冻结；恢复后提醒重新计时。Rime 仍保存数字计数。
- **停止计数**：用 Rime 方案菜单的“隐私暂停”，或切换到其他输入方案。恢复不会补发暂停期间的内容。
- Lua 只将 `版本、日期、随机会话标识、序号、累计码点数` 写到 Rime 用户目录下 `corgi-stats`。不会写中文、拼音、窗口标题、应用名、剪贴板、原始按键。
- 普通 Rime `commit_notifier` 上屏才计数。英文直通、粘贴、其他输入法不计；脚本直接提交、Squirrel 的直接 commitComposition 等绕过 notifier 的路径不保证覆盖。组合标记和 emoji 按 Unicode 码点而非视觉字形计数。
- 首次启动用当前累计值作基线，不补放历史鼓励。记录损坏或桥接失败不会阻止输入。
- “今日”使用本地系统日期；时区/系统时钟变化可能影响统计，不是工时考勤工具。
- 自动保留最近 7 个本地自然日计数；桌宠启动/跨日时，仅清理符合本协议的旧数字记录，异常文件和未来日期文件不删。单次扫描最多 4096 个匹配文件，达到上限会显示异常提示，而不是无限扫描。
- 清除历史：先退出桌宠和 Rime 服务（仅切换输入法不等同退出），备份后删除 `corgi-stats` 内计数文件。重新启动会从新会话计数。

## 开发

需要 Node.js 22+、npm；首次安装需要网络下载 Electron。运行时离线。

```sh
npm ci
npm test
npm start
npm run dist:win  # 在 Windows 构建 x64 ZIP
npm run dist:mac  # 在 macOS 构建 arm64 与 x64 ZIP
```

`npm run preview` 仅在本机打开视觉预览，不具备桌面能力或真实输入桥接，不能算原生验收。

## 卸载与恢复

右键设置 → 隐私与维护 → 卸载扩展，确认后恢复安装前配置、删除未修改的扩展，保留原配置备份和计数记录。然后重新部署 Rime。若安装后配置被用户改动，自动卸载会拒绝，以避免覆盖用户配置。手动卸载：从 `default.custom.yaml` 的 schema_list 或 schema_list/+ 中只移除 `corgi_pinyin`，删除本包添加的 schema 和 Lua 文件；不要整体覆盖后来修改过的配置。

安装/卸载使用独占 `.corgi-install.lock`，配置通过 fsync 临时文件和 rename 替换。若进程异常退出导致锁残留，先核对备份、目标文件和安装记录再手工移除锁；不盲目自动回滚用户配置。

## 验证边界

详见 `docs/ACCEPTANCE.md`。Linux 上的 Node/Lua 单测与截图不代表 macOS/Windows 实机通过。原生系统第三方应用上屏、输入焦点、屏幕缩放、Unicode Windows 用户目录、未签名启动均必须在对应系统验收。此版本是可测试预览交付，不宣称双平台正式发布完成。

## 从 0.1 升级到 0.2

退出旧桌宠，解压并运行新的桌宠包。Rime 计数协议和扩展文件未变，已经安装的柯基拼音无需重装；设置会继续从同一应用数据目录读取。新增喝水/休息提醒默认为 30/45 分钟，可在齿轮面板关闭或修改。
