# 0.5 仅触及柯基展开、六方向固定环

首次展开由真实柯基 SVG 的 corgi-body 区域触发，不由外围透明容器触发。展开后柯基与六图标共享保留区域，移向图标穿过间隙不会关闭；离开 180 毫秒后关闭。六按钮为 44 像素，固定在椭圆六方向，出现/悬停均不平移或缩放命中区域。即时点按对应真实功能，点击不误触拖动。

原有行走停止、拖动、提醒、设置与右键入口保持。以下旧版章节是保留功能的历史说明，位置与触发细节以本节为准。

# 0.4 悬停环绕快捷操作

靠近柯基显示六个独立圆形图标：♡摸摸、🍪饼干、💧喝水、🌿休息、◷专注/取消、⚙设置。均执行真实对应操作，具有中文悬停标题和无障碍名称。按钮不触发柯基拖拽或单击动作。

柯基与图标共用一块悬停区域，跨越间隙不会立即关闭；离开该区域 180 毫秒后收起，重新进入会取消收起。离开窗口立即隐藏。拖动过程、设置打开及提醒待处理时隐藏。靠近时仍通过现有 hover 状态暂停走动，不改变不抢焦点策略。

以下为此前版本保留的手势/菜单说明。

# 0.3 自然互动与散步

没有常驻底部按钮。单击摸摸；300 毫秒内双击喂饼干；按住拖动换位置；右键打开完整操作菜单。获得焦点时也可用 Shift+F10 或菜单键打开菜单。菜单保留喝水、休息、专注、暂停、设置、退出，并加入自动散步开关与「散步一小圈」。

设置中的散步开关立即保存。「散步一小圈」点击后关闭设置并移开鼠标；手动请求会等交互结束后开始。自动走动只在最近两分钟有新 Rime 计数或专注开启时发生。鼠标靠近、设置/提醒卡片、拖动、暂停都会停下，关闭散步会立即停止，重新启用后重新计时。不会读取应用名、正文或键盘。

下方为 0.2 保留功能说明，按钮入口现在位于右键菜单或设置中。

# 0.2 逐项操作与反馈

| 操作 | 真实状态变化 | 可见反馈 |
|---|---|---|
| 点击柯基 / ♡ | 摸摸次数 +1 | 爱心、亲昵动作、回应文案 |
| 饼干 | 饼干次数 +1 | 咀嚼动作、喂食文案 |
| 💧 / 现在喝水 | 打开喝水待处理提醒 | 水碗动画、喝水卡片 |
| 现在休息 | 打开休息待处理提醒 | 伸展动作、休息卡片 |
| 喝好了 / 休息好了 | 对应完成次数 +1，下一次从现在重新计时 | 确认文案、计数、卡片关闭 |
| 10 分钟后 | 此提醒重新安排为 10 分钟后 | 延后文案、卡片关闭 |
| 关闭此提醒 | 关闭对应类别并持久保存 | 关闭文案、设置开关变为关闭 |
| 保存提醒 | 校验并保存两类间隔/开关 | 成功文案、下一次时间；无效值显示错误 |
| 专注 | 开始 25 分钟倒计时；再次点击取消 | 倒计时 / 取消文案；到期打开休息卡片 |
| 暂停 | 暂停奖励和提醒，冻结专注 | 睡眠动作、暂停文案；恢复后重新计时 |
| 保存阈值 | 更新下一次鼓励门槛 | 保存值确认；无效值显示错误 |
| 拖拽 | 移动原生窗口并夹紧屏幕边缘 | 悬挂动作、落地确认 |
| 右键菜单中的设置 / 关闭 | 打开可聚焦设置 / 恢复不聚焦 | 设置面板出现或消失 |
| 选择目录 | 原生目录选择器确认后更新路径 | 新路径或明确取消文案 |
| 安装 / 卸载 | 原生确认框 + 安全配置操作 | 成功、取消或错误，不伪造成功 |

喝水/休息「完成」是用户自报记录，并不声称传感器验证真实饮水或运动。系统输入计数与这些交互计数分开。

操作视频若由 Linux Electron 录制，仅证明该环境真实 GUI 操作；不是 macOS/Windows 原生输入法验收。安装/卸载必须在有 Rime 的对应系统验证，不能用模拟成功画面替代。

若已关闭的类别通过“现在提醒”手动弹出，再选择“10 分钟后”，会明确重新开启该类提醒并保存，确保承诺的稍后提醒实际发生。

取消专注后，若已经走在途中，会走完当前短程（约 8 秒以内）；没有其他工作信号就不再开始下一圈。需要立刻停下可将鼠标移近，或关闭自动散步。原生菜单打开期间也不会走动。
