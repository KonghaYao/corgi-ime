# 0.4 预览版：悬停环绕互动

鼠标靠近柯基时出现六个独立可点击圆形按钮：摸摸、饼干、喝水、休息、专注/取消、设置。离开收起，底部仍无常驻图标。原有漫步、拖动、右键菜单、提醒与 Rime 计数功能保留。

## 验证
- 干净 npm ci 成功；修复了旧版源码锁文件的依赖范围污染。
- Node 66/66 自动测试、真实 Lua 解释器加 Rime API stub 测试通过。
- 真实 Linux GUI：六按钮均产生对应反馈，摸摸/饼干/喝水/休息各增加一次记录；专注开始及取消正常。
- 真实 Linux GUI：离开隐藏、再次靠近恢复、拖动过程隐藏与释放恢复、提醒/设置不被图标遮挡。
- 真实 Linux GUI：自然漫步中靠近停止，随后图标仍可点击；拖动到屏幕四边，六图标未裁切，边缘按钮可点。

录像及其操作记录另附。mock 自动测试不是原生系统验收，Linux 结果不能代替 macOS/Windows。

## 限制
macOS/Windows 原生运行、系统 Rime 真上屏、不同 DPI/多屏、透明区域穿透、签名与权限仍需对应实机验证。二进制是未签名/未公证预览包。非聚焦窗口下键盘菜单导航不保证可用，主操作路径为鼠标。原生输入法和词典仍需另装官方版本，桌宠不是独立实现的系统输入法。
