# 验收清单

- 重复事件和双槽半写读数去重、高水位不回退。
- 启动基线、奖励阈值、冷却、暂停不补发、专注/休息提醒。
- 安装保留原有配置、卸载逐字恢复、缺词典/坏 YAML 安全拒绝。
- 配置被修改后拒绝卸载，独占锁拒绝并发覆盖，失败源文件恢复。
- Lua 在真实 Lua 解释器下运行，但 Rime API 由 stub 模拟，不是真 Rime 集成测试。

## 性能预算与发布门槛

目标：输入回调仅一次短文件写，无网络或外部进程；桌宠每 1.5 秒读数字快照。尚未测 macOS/Windows 输入延迟 p95、RSS、长时资源增长，不声称达到特定数值。正式发布前应测至少 1 小时、10000 次上屏、多个进程切换、目录不可写和崩溃恢复，并完成双平台签名/公证。

## 0.3 漫步与自然交互（双平台仍待实机）
- 空闲桌面不显示底部图标，单击摸摸/双击饼干不重复记为摸摸，右键完整菜单可发现。
- 设置或菜单关闭自动散步后立即停止，重启保持关闭。
- 有新 Rime 计数或专注开启后等待 30–50 秒观察实际窗口坐标移动，不是仅动画。
- 靠近柯基、拖动、开设置、提醒出现、暂停陪伴时停止；释放后无跳跃。
- 当前屏幕工作区边缘、负坐标副屏、拔屏、缩放改变时窗口可找回；不跨显示器追随光标。
- 在 TextEdit/Notepad 正输入时观察漫步不夺焦点，透明区域鼠标不阻塞前台应用。
- 提醒/喂食/摸摸/拖动/设置和安装功能仍可经右键菜单访问。

## 0.4 悬停快捷操作
- 空闲不显示快捷按钮，鼠标靠近柯基时显示左右环绕六图标。
- 从柯基移动到任意图标和其间隙不会提前收起；离开收起。
- 每个图标可独立点击，执行摸摸、饼干、喝水、休息、专注/取消、设置，且不误触拖动或摸摸。
- 拖动时隐藏，松开后恢复；提醒或设置打开时隐藏，不挡对应操作。
- 悬停依然暂停走动；Mac/Windows 需要实机确认透明穿透模式下能从柯基移动到图标并点击。

## 0.5 严格悬停、环形与新表情
- 鼠标只进入透明外环时不显示按钮；进入真实柯基身体才显示。
- 六按钮位于上、右上、右下、下、左下、左上；出现或悬停不移动/缩放命中目标，支持快速点击。
- 宠物到按钮跨间隙不消失；离开收起；提醒/设置与拖动行为回归。
- 新柯基的歪头、眨眼、转眼、耳朵/尾巴小动作以及饼干道具不遮挡按钮或改变窗口焦点。
- 所有视觉与环按钮证据明确平台，不把 Linux 画面当作 macOS/Windows 原生测试。
