# 0.3 Linux 实际桌面验证

本次为真实 Linux X11 Electron GUI，通过鼠标操作并用 ffmpeg X11 capture 录制。不是浏览器模拟，未进行 Mac 或 Windows 原生验收，未验证原生 Rime 中文上屏链路。

## 通过的操作
- 默认界面无底部工具图标，首次短提示说明单击、双击、右键。
- 真实拖窗，从右下移至屏幕中部。放开后没有立即跳回旧位置。
- 双击柯基获得饼干反馈。
- 右键打开完整菜单；手动散步完成真实位移，窗口 x524→652，步行动画可见。
- 开启25分钟专注，等待真实自动漫步，x652→780。期间外部 Thunar 窗口持续 focused=true，柯基 focused=false。
- 再拖动柯基至 x420,y306，设置面板打开期间位置稳定。
- 设置取消工作时自动散步，关闭面板后显示关闭反馈并停留原位。
- 右键现在喝水、喝好了，水碗及完成反馈保留。

## 发现并修复
首次实际菜单关闭后 hovered 状态残留，手动散步没有启动。实现者增加真实指针位置校验及菜单开启期间阻塞。退出重启加载修复后，上述实际位移通过。交付录像来自此次重启之后。

## 未通过或未完成
- 非聚焦桌宠窗口的键盘菜单导航未通过：右键菜单后 Down/Return 没有触发。实现者选择保留不抢焦点，并在说明中标为限制，不能宣称完整键盘可访问。
- 鼠标靠近时曾观察停止，但发生在接近目标点，不能单凭这次操作证明中途立即停止；该项需进一步验收。
- 没有验证减少动态效果设置、读屏、多显示器、睡眠恢复及长期行为。
- 自动漫步由专注状态触发；没有伪造输入字符或声称已验证工作输入计数。
