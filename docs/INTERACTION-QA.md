## 证据分层

- 纯逻辑与模拟时钟：验证状态机、边界、持久化数据语义，不证明系统窗口行为。
- mock Electron 主进程：运行实际 main 代码，检查动作路由与状态；不是原生实机。
- 真实界面操作与视频：须说明所在平台及模拟的输入/时钟部分；视频中的真实按钮应走实际业务逻辑。
- 原生 macOS / Windows：输入法安装、第三方应用上屏、焦点、穿透、多屏和签名仍需对应系统验证。
