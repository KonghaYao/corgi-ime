# 0.3 预览版交付说明

## 更新
- 删除柯基下方常驻图标，单击摸摸、双击喂饼干、右键访问全部功能。
- 工作信号（最近 Rime 数字计数增加或专注计时）触发低频短程漫步，腿部交替动画。
- 可关闭并持久保存；鼠标靠近、拖动、设置、原生菜单、提醒、暂停陪伴会停止漫步。
- 当前显示器工作区边界约束；睡眠长时间间隔不会一次跳很远。
- 自然入口保留喝水、休息、专注、暂停、输入法配置和退出功能。

## 实际证据
- Node 自动回归 62/62；Lua 真实解释器 + 模拟 Rime API 测试通过。
- Linux 实际 GUI：无下栏、双击饼干、拖动、右键；手动和专注自动散步发生真实窗口坐标变化；外部窗口保持焦点；关闭散步反馈正常。视频只代表 Linux。
- 三份 ZIP 是从 Linux 交叉构建的 macOS x64/arm64、Windows x64 包；静态一致性核验见 PACKAGE-QA.md。

- 包未签名/公证，不保证首次启动不被安全机制拦截；不要全局关闭系统防护。
- 非聚焦桌宠窗口的键盘菜单导航不保证可用。当前主交互是鼠标右键，不声称完整键盘可访问。
- Linux 为保证鼠标可交互采用不穿透回退；不能据此推断 Mac/Windows 透明区域穿透表现。
- 自动漫步不读取键盘或活动应用。非 Rime 输入不产生工作信号，可使用专注或手动散步。
- 散步取消专注后可走完当前短程；即时停止可移近鼠标或关散步。
